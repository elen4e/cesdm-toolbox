GenerationUnitEnergyAssetInstance
Deployed generation asset with topology, dispatch, and optional dynamics data. Technology-specific design attributes live on subclasses (Hydro-, Wind-, Solar-, ThermalGenerationUnit); shared dispatch/topology fields stay here.
Carrier rule: the injected carrier is implied by atNode → CarrierDomain when a single-carrier bus is attached. Optional hasInputCarrier / hasOutputCarrier are overrides for imports or multi-fuel cases. Bus classification (PQ/PV/slack) lives on ElectricalBus.powerflow_bus_type, not on the generator.

HydroGenerationUnitGenerationUnit
Generation unit that converts hydraulic head or flow into electricity, optionally with pumping (hydro_machine_kind = reversible).
Couples to HydraulicStorageUnit water bodies via drawsFromHydraulicStorage / dischargesToHydraulicStorage (machine → basin; no inverse suppliesResourceTo). Natural inflow belongs on the water body, not on this generator. hasTechnology is inherited from GenerationUnit → GeneratorType.
