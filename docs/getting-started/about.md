# About

**CESDM (Common Energy System Domain Model)** is an open, schema-driven framework for interoperable energy-system modelling — one agreed description of a system so modellers can exchange harmonised data, compare results, and reuse models across tools instead of maintaining separate copies per solver.

CESDM is developed within the [SWEET-CoSi](https://www.sweet-cosi.ch/) project (SWEET — Co-evolution of the Swiss Energy System and Society), funded by the Swiss Federal Office of Energy, as Task 1.9: conceptual and methodological foundations for common energy-system representations.

This is a research prototype and methodology demonstrator, not a finalised or normative version of CESDM — see the [full disclaimer](disclaimer.md) for what that means in practice.
